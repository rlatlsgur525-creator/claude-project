# 조사 기록 2026-10-26 (첫 시험)

- 플랫폼: 네이버 블로그 (로그인 없이 열림, 공개 확인)
- 출처: https://blog.naver.com/ho_yu/224438582016
- 제목: "블로그 글쓰기 팁, 구조 잡고 AI로 초안 뽑는 방법 완벽 정리"
- 접속 시각: 2026-10-26 (ego-lite 브라우저, 모바일 주소로 본문 확인)

## 선정 이유
검색어 "블로그 글쓰기 구조 팁" 공개 결과에서 구조가 뚜렷한 글. 한계: 검색 결과를 최신순으로 봤고 조회수는 확인하지 못했다. 그래서 "인기 글"이라고 단정하지 않는다(인기 판정은 미검증).

## 구조 분석표
| 항목 | 내용 |
|---|---|
| 제목 유형 | 핵심어 + 방법 + "완벽 정리" (긴 키워드형) |
| 도입 | 독자 공감 문제("구성에 따라 노출이 다르다") → 내 실패담 → 이 글에서 풀 내용 예고 |
| 전개 | [목차] 4개 제시 → 번호 소제목 1~4. 소제목마다 짧은 문단과 빈 줄 |
| 설득 장치 | "예를 들어" 구체 사례, 1·2·3단계 번호 절차, 건축도면 비유 |
| 마무리 | 변화 후기 + 감정(불안감이 줄었다) |
| 눈에 띄는 작성 규칙 | **독자 질문 순서대로 문단 배치** (제목에서 독자가 궁금한 걸 찾고 그 순서로 답한다) |

## 근거가 필요한 주장 (그대로 쓰지 않는다)
- "AI 초안 2분", "조회수 5~10 → 30~50", "월 8~10개 → 주 3~4개"는 글쓴이 개인 경험이며 검증할 수 없다.
- 글 후반은 특정 유료 서비스를 소개하는 홍보 성격이다. 초안에서는 그 서비스 이름과 효과를 쓰지 않는다.
