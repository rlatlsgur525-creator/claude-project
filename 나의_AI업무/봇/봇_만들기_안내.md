# 디스코드 봇 만들기 안내 (캡틴이 직접 하는 부분)

토큰은 비밀번호와 같아요. 대화창이나 이 폴더(OneDrive)에 적지 마세요.

## 1. 서버와 방 만들기 (디스코드 앱)
1. 왼쪽 + 버튼 → 직접 만들기 → "나의 AI 업무" 서버
2. 텍스트 방 6개를 아래 이름 그대로 만든다: `비서실`, `조사`, `브리프`, `블로그발행`, `쓰레드`, `결재`

## 2. 봇 만들기 (브라우저)
1. https://discord.com/developers/applications → New Application → 이름 "AI비서실"
2. 왼쪽 Bot 메뉴 → **Message Content Intent**를 켠다 → Save
3. Bot 메뉴의 Reset Token → 토큰 복사 (이 화면 밖으로 꺼내지 않는다)

## 3. 서버에 봇 초대
1. 왼쪽 OAuth2 → URL Generator
2. Scopes: `bot` 체크
3. Bot Permissions: View Channels, Send Messages, Read Message History 체크
4. 만들어진 주소를 브라우저에 열어 "나의 AI 업무" 서버를 고른다

## 4. 내 사용자 ID 확인
디스코드 설정 → 고급 → 개발자 모드 켜기 → 내 이름을 우클릭 → 사용자 ID 복사

## 5. 설정 파일 만들기 (OneDrive 밖)
파일 위치: `C:\Users\rlatl\.ai-work-bot\.env` (폴더가 없으면 만든다)
내용 두 줄:
```text
DISCORD_TOKEN=여기에 토큰
ALLOWED_USER_ID=여기에 내 사용자 ID
```

## 6. 실행 (Claude에게 설치 승인 후)
- 설치(처음 한 번): 봇 폴더에서 `npm install` — 외부 패키지(discord.js)를 받는 설치라서 Claude가 승인을 받고 진행해요.
- 실행: 봇 폴더에서 `npm start`. 창을 닫거나 PC를 끄면 봇도 멈춰요.

## 쓰는 법 (#비서실에서만 말하기)
- 새 지시: 그냥 문장으로 말한다 → 조사 → 브리프까지 진행하고 방향 확인에서 멈춘다
- 방향 확인: `T-0001 진행` 또는 `T-0001 수정: 바꿀 내용`
- 승인안은 #결재에 올라오고, 승인·수정 요청·반려 버튼을 누른다 (발행은 직접)
- 원인 찾기: `왜 이렇게 나왔어? T-0001`
