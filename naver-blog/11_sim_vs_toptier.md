### 2-1. 글 흐름 지도 (분석한 10편)

**Franky** · 「"뭘 사야 후회 없을까?" 마샬 스탠모어4 액톤4 차이 비교」 / 「"방전되면 끝일까?" 전기차 배터리 수명 교체 주기 비용 보험 총정리」
> 쇼핑커넥트 고지 → 배경 3문단 ("저 역시 관심") → "오늘은 ~정리해 드리겠습니다" → 목차 4개 → ①변화 ②스펙 비교표 ③상황별 추천 ④마무리 → "도움이 되었기를"
- 결론 위치: 첫 화면 없음. 배터리 글은 1번 소제목 안에서 "결론부터 말씀드리면"
- 두 편 뼈대 동일. 우리 상투어 목록 중 3개 사용("오늘은", "결론부터", "도움이 되셨길" 계열)

**제철건강 노트** · 「"23알이면 끝이라고?" 아몬드 하루권장량…」 / 「"냉장고에 바로 넣었더니 그대로예요" 키위 후숙 보관법…」
> 질문 1줄 → **답 1줄 (2줄째)** → 근거 1줄 → "~까지 풀어요" → [검색어 그대로] 소제목 5~7개 × (표 → 굵은 번호 3개, 각 2줄) → 추가정보 Q&A 3개 → 주의 1줄 → **1인칭 한 줄로 끝** ("23알을 알고 나선 손이 멈추네요")
- 한 줄 7~15자, 문단 2줄. 표 3개/편. 경험 1~2줄/편
- 두 편 뼈대 완전히 동일. 제목은 따옴표 속 독자 실수 + 하위 검색어 나열 (40~50자)

**으너니** · 「방콕 호텔 추천 순위 7곳 수영장과 BTS 위치 비교」 / 「홍콩 옥토퍼스카드 구매 충전 환불 방법 + …」
> 공감 + 내 경험("방콕 한달 살기 하면서") → "평점 보면 놀랄걸요" → **비교표 바로** → 항목별 소제목 7개 × (특징 + 운영시간 + 제휴 링크 2개) → "즐거운 여행 되세요"
- 결론 없음 (순위표가 결론 역할). 구어체·감탄("하아… 방콕 마렵네요"), 제휴 링크 소제목마다
- 옥토퍼스 글은 계산 예시("HK$30 + 50 − 11 = 69") 포함

**리샤** · 「모니터 어댑터 교체 전 전압과 전류, 단자 규격 확인법」 / 「RPA란? 매크로 프로그램과 다른 자동화 원리」
> 굵은 부제 2줄 → 상황 1줄 → **핵심 규칙 1줄 (3줄째)** → 목차 3개 → 1·2·3 소제목 (설명형 문단, 숫자 예시 "19V 2A = 38W") → 요약 문단 3~4줄 → 해시태그
- 경험 0줄. 출처는 본문 속 언급(삼성전자서비스, Microsoft Power Automate)
- 두 편 뼈대 동일. 제목이 우리 공식과 가장 비슷 ("검색어 + 답의 범위", 20~30자)

**김주부별전** · 「허리 삐끗했을때, 허리통증 약 병원 주사」 / 「당뇨 초기증상 7가지, 몸이 보내는 신호」
> 질문형 도입 2문단 → 인용박스 소제목 4~5개 (질문형) × ①②③ 항목 → 위험 신호 → 요약 2문단 → **출처 박스** (질병관리청, CDC, MedlinePlus 등) → 태그 10개
- 결론: 당뇨 글은 1줄째 답, 허리 글은 끝에 가서 답. 경험 0줄
- 두 편 뼈대 동일

## 4. 판정 전에 알아야 할 관찰 (우리 규칙과 부딪히는 사실)

1. **새 탑티어 5곳 중 4곳이 블로그 안에서 같은 틀을 매번 쓴다.** 우리 지침의 "구조 반복 = 저품질 신호"(01_rules 6장)는 운영자 분석 글 3편에서 온 규칙이고 네이버 공식 문서가 아니다. 이 5곳은 틀을 고정하고도 상위권이다. 다른 점은 **틀은 같아도 주제·검색어·표 내용이 매번 다르다**는 것.
2. **발행량도 우리 상한(하루 1편)보다 많다.** 제철건강은 하루 최대 7편.
3. **제철건강의 흐름이 우리 신념 2(엄지 세 번 안에 답)를 가장 철저히 지킨다.** 질문 → 답이 2줄 안, 소제목이 곧 검색어, 표가 소제목마다.
4. **경험·출처·기준일은 우리가 더 많다.** 5곳 중 출처를 다는 곳은 2곳, 경험 문장이 실제로 있는 곳은 2곳.
5. **우리 시뮬레이션의 약점 W2(새 상투 패턴)는 "고정 틀"과 다르다.** 고정 틀은 의도된 형식이고, W2는 섞으려다 무심코 남은 반복이다. 판정 기준에 따라 해석이 갈릴 수 있음.

## 5. 한계

- 블로그차트 순위는 블로그차트 자체 지표이고, 방문자·조회수는 비공개라 확인하지 못했다.
- 블로그당 2편만 봤다. 모바일 페이지 텍스트 기준이라 이미지 수·배치는 세지 않았다.
- 시뮬레이션 5편은 빈칸이 남은 초안이다. 실제 경험·숫자가 채워지면 흐름 평가가 달라질 수 있다.
