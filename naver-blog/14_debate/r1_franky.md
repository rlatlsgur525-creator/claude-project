## A. 내 블로그 관찰

**공감·댓글 수: 확인 불가.** RSS와 모바일 본문 텍스트 어디에도 숫자가 안 나왔다. 그래서 공감 순이 아니라 **화재보험과 구조가 닮은 글**(손실 숫자, 오해 깨기, 문제 해결) 3편을 골랐다. 하루 3~4편, 08·10·12·15·18·20·22시 고정 발행.

| 글 | 흐름 지도 | 계속 내리게 만드는 장치 (위치) |
|---|---|---|
| ① "모르면 최소 50만원 손해" 인터넷 사은품 (224440630495) | 독자 상황 질문(굵게) → 내 실수 고백 → 따옴표 속 오해 → "그래서 오늘은" 범위 → **목차 4** → 1.왜 차이 나나 → 2.얼마 받나 → 3.체크리스트 → 4.추가 팁 → 마무리 → 업체 링크 | 제목 손실 숫자 / 2번 첫 줄 **"그렇다면 얼마?"** 다리 질문 / 2번 목록 끝 👉 합계 "최대 132만 원" / 3번 "주의할 점도 있습니다" 반전. **※ 업체 홍보글이라 내용은 베끼면 안 됨. 구조만 본다.** |

**공통 뼈대**: 굵은 첫 문장 → 범위 약속 → 번호 목차 → 번호 소제목, 소제목 첫 문장은 늘 굵게(굵은 글씨만 읽어도 이어짐) → 구분선 → 끝 한 줄 원칙.
**내 약점(인정)**: 서론이 3~4문단으로 길고, "도움이 되셨길" 같은 인사로 닫는다. 이건 따라 하지 마라.

## B. 화재보험 초안 진단 (08 v1.2)

**제목 클릭률: 낮다.** "가게 화재보험 꼭 들어야 할까?"는 검색 결과에서 보험사·설계사 글 10개와 **똑같은 꼴**이다. 정작 제일 센 훅 두 개가 본문에 묻혀 있다. ① 첫 줄의 독자 말("건물주가 들었으니…") ② 4번 구간의 "2,000만 원 들고 1,500만 원". 이 둘 중 하나는 제목에 올라와야 한다.

| 구간 | 판정 | 이유 |
|---|---|---|
| 첫 줄 독자 따옴표 | **잡는다** | 내 글 첫 줄과 같은 장치. 그대로 둔다 |
| "11월 불조심 강조의 달이면" 2줄 | **이탈 위험** | 독자 질문과 상관없는 달력 얘기. 첫 화면 2줄을 버린다 |
| 결론 박스 (8줄째) | **이탈 위험** | 법조문 같은 긴 한 문장. 엄지가 건너뜀 |
| 판정표 | **최대 이탈 지점** | 표가 제목 질문("꼭 들어야 할까?")에 **완전히** 답한다. 그 아래에 더 받을 게 있다는 약속(목차·예고)이 없으니 "나 대상 아님" 하고 나간다 |
| 의무보험만으로 될까? | 잡는다 | "한 푼도 나오지 않아요"가 좋다. 그런데 **과태료 300만 원**이 여기 묻혀 있다. 앞으로 올려야 할 손실 숫자다 |
| 월세 가게 | 잡는다 | "네, 불이 내 가게에서 났다면요." 첫 줄이 강하다. 2문항 체크도 좋다 |
| 집기 비례보상 | **글의 심장** | 가장 놀라운 숫자인데 4번째라 독자가 여기까지 못 온다 |
| 재조달가액 | **이탈 위험** | 줄글뿐(평가 S3 불통과 지점). "180일 서면"은 모르면 손해 보는 내용인데 밋밋하게 지나간다 |
| 옆 가게 번짐 | 약함 | "~편이 안전합니다"로 김빠지게 끝난다 |
| Q&A | 아깝다 | **"1년 2만~6만 원"**(30~60평, 2022 배민 기준)은 클릭 숫자인데 맨 끝에 있다 |
| 마무리 | 약함 | "다음 글에서는"은 지침 상투어이고, 아직 없는 글이라 누를 수도 없다 |

## C. 빼기 / 넣기 / 베끼기

**빼기**
1. 첫 화면의 "11월 불조심" 2줄 → 시기 훅은 태그·썸네일로 충분하다. 첫 화면 줄이 아깝다.
2. 결론 박스 "한 문장 결론" → 표가 답을 대신하니 박스는 중복이다.
3. 지침 3장 "감정 훅 **3편에 1편**" 상한 → 훅 없는 제목은 검색 1페이지에서 안 눌린다. 매 편 넣는다.
4. 마지막 줄 "다음 글에서는 ~볼게요" → 없는 글을 예고하면 클릭으로 안 이어진다. 발행된 글이 생기면 내부 링크 1줄로 바꾼다.

**넣기**
1. **번호 목차(5개 이하)를 첫 화면 바로 아래에** → 평가 S1 '예고'를 한 번에 통과한다. 독자는 목차에서 자기 질문을 보고 내려간다.
2. **목차 항목에 열린 고리 1개** ("2천만 원 들었는데 1,500만 원?") → 답을 미리 알아도 '왜'가 남는다.
3. **소제목 첫 문장 굵게** → 대충 훑어 내리는 40~60대 사장님도 굵은 글씨만으로 뜻을 따라온다.
4. **구간 끝 다리 질문 1줄** ("그럼 월세 가게는요?") → 다음 구간으로 엄지를 넘겨준다.
5. **"내 칸 찾기" 분기**(▶ 1층 / ▶ 지하·2층 이상, ▶ 월세 / ▶ 내 건물) → 자기 경우를 찾아 내려가게 만든다.
6. **○/✕ 판별 1개** (재조달가액) → 줄글 구간을 시각 요소로 바꾼다.
7. **끝 한 줄 원칙** ("A가 아니라 B예요") → 저장·공감을 부르는 문장이다. 상투적인 인사는 넣지 않는다.

**베끼기 (구조만)**
| 내 장치 | 화재보험에 옮길 자리 |
|---|---|
| 따옴표 독자 목소리 제목 | 제목 검색어 바로 뒤 |
| "끝까지 읽으면 ~" 약속 1줄 | 첫 화면 마지막 줄 |
| 번호 목차 → 번호 소제목 1:1 | 목차 5 = 소제목 5 |
| 중간 손실 숫자("수리비 폭탄"류) | 2번 과태료 300만, 4번 1,500만 |
| "의외로 많습니다 → 하지만" | 2번 의무보험 오해 |
| ▶ 분기 | 1번 층별, 3번 월세/자가 |
| A vs B 구별법 (점등 vs 깜빡) | 2번 "의무보험이 주는 돈 vs 안 주는 돈" |

베끼지 말 것: 제휴·업체 링크, 서론 3~4문단, "도움이 되셨길"류 인사.

## D. 내가 이 주제를 쓴다면

**제목 3안** (사실은 초안 범위 안)
1. 가게 화재보험 "건물주가 들었으니 괜찮죠?" 세입자가 물어줄 돈 3가지 (35자)
2. 가게 화재보험 2천만 원 들어도 1,500만 원만 나오는 이유? 집기·의무보험 (38자)
3. 가게 화재보험 의무보험만 들면 끝? 과태료 300만 원과 빠진 보상 정리 (36자)
→ 1안 추천. 첫 줄 독자 말과 같은 말이라 제목을 누른 사람이 첫 화면에서 바로 이어 읽는다.
※ 2안의 1,500만 원은 초안의 **예시 계산**(실제 가치 5,000만·손해 3,000만)이다. 본문에서 '예시'라고 밝혀야 한다.

**뼈대**
- 첫 화면 → 목차 5
- 1. 우리 가게, 의무보험 대상일까? (▶ 층별 판정표 + 확인처)
- 2. 의무보험이 **안 주는** 돈은 따로 있어요 (네 방향 도식, 과태료 300만)
- 3. 월세 가게, 건물주 보험이 있어도 나한테 청구될까? (구상 + 계약 전 2문항)
- 4. 2천만 원 들었는데 1,500만 원? 집기 금액 계산 (비례보상 표)
- 5. 새것 값으로 받으려면, 옆 가게로 번지면 (○/✕ 2개)
- Q&A 3개 → 마무리

**첫 화면 전문**
> "건물주가 화재보험 들어놨으니까 저는 괜찮죠?"
> 가게 사장님께 제일 자주 듣는 질문이에요.
> 반은 맞고, 반은 틀려요.
> 건물주 보험은 **건물주 재산**만 지켜요.
> 불이 내 가게에서 시작되면
> 손님·옆 가게·건물주에게 물어줄 돈은 사장님 몫이에요.
> 층과 평수에 따라 법으로 꼭 드는 의무보험이 있고,
> 안 들면 과태료가 최대 300만 원이에요.
> 그런데 진짜 큰돈은 **의무보험이 안 주는 쪽**에서 나와요.
> 끝까지 보시면 우리 가게가 대상인지,
> 집기를 얼마로 들어야 덜 깎이는지까지 계산돼요.

(키워드 '가게 화재보험'은 1번·2번 소제목 본문에 2회 더 넣어 지침 2-1 #8을 맞춘다.)

**궁금증 장치 배치**
| 자리 | 장치 |
|---|---|
| 첫 화면 | 열린 고리 "의무보험이 안 주는 쪽" (2~4번에서 풀림) |
| 목차 | 4번 항목 "2천만 원 들었는데 1,500만 원?" |
| 1번 끝 (최대 이탈 지점) | 굵게: "대상이 아니어도 끝이 아니에요. 불나면 나가는 돈은 따로예요." → 2번 |
| 2번 | A vs B 도식 + 굵게 "3·4번은 의무보험에서 한 푼도 안 나와요" |
| 3번 | ▶ 월세 / ▶ 내 건물 분기, 끝 다리 질문 "그럼 내 집기는 얼마로?" |
| 4번 | 계산표 앞에 "왜 1,500만 원일까요?" 질문 1줄 → 표 |
| 5번 | ○/✕: "영수증만 있으면 새것 값?" → ✕ 실제로 다시 사야 함 |
| Q&A 마지막 | 갱신일 질문으로 다음 고민 연결 (N-b) |

**마무리**: 한 줄 원칙 + 할 일 1개.
"가게 화재보험은 '들었냐'보다 **'누구 돈을 막아 주냐'**예요. 오늘은 우리 가게가 의무보험 대상인지, 갱신일이 언제인지만 확인해 보세요." 그다음 약관 안내 1줄, 기준일·출처를 둔다. "다음 글"은 쓰지 않는다.

## E. 정답을 앞에서 말해도 계속 읽게 만드는 내 방식

1. **일반 답은 주고, '내 경우'는 아래에 둔다.** "반은 맞아요"까지만 위에서 말한다. 내 층, 내 계약, 내 집기 금액은 내려가야 나온다. 그래서 ▶ 분기와 계산이 필요하다.
2. **답 뒤에 '그런데'를 하나 남긴다.** 결론을 말한 바로 다음 줄에 더 큰 손실을 예고한다. 답이 끝이 아니라 입구가 된다.
3. **목차가 계약서 역할을 한다.** 받을 것 5개를 위에 적어 두면 독자는 아직 못 받은 항목을 받으러 내려간다.
4. **굵은 글씨로 훑기 층을 만든다.** 대충 내리는 사람도 굵은 글씨 문장마다 보상을 하나씩 받아 멈추지 않는다.
5. **숫자를 구간마다 하나씩 나눠 둔다.** 300만, 10억, 1,500만, 180일. 다음 숫자가 궁금해서 내려간다.

## F. 다른 블로거와 부딪힐 입장

- **양보 못 하는 것: 매 편 제목에 따옴표 독자 말이나 손실 숫자를 넣는 훅, 그리고 첫 화면 번호 목차.** 정보가 아무리 정확해도 안 눌리면 0이다. 지침 v1.4의 "3편에 1편" 상한은 없애야 한다. 단, 검색어 15자 안 규칙은 지킨다. 훅은 검색어 **뒤**에 둔다.
- **양보할 수 있는 것: 내 블로그식 키워드 나열 꼬리** ("~가격 할인 방법 총정리"). 40~60대 사장님이 읽기 힘들고, 평가 T6에서도 감점됐다. 문장으로 읽히는 제목이면 된다.
