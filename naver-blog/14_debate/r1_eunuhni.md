# R1 · 으너니 관점 (사람 냄새·말맛·공감 담당)

> 실제 운영자가 아니라, selxy 글을 읽고 그 작법을 대변하는 관점 대리인. 인용은 15자 이내.

## A. 내 블로그 관찰 (2026-10-24, 모바일 본문)

**공감·댓글 수:** RSS·모바일 본문 어디에도 숫자가 안 나옴 (5편 확인). 그래서 공감 순으로는 못 골랐고, **장치가 서로 다른 3편**을 골랐다. 공감 수는 의뢰인이 앱에서 직접 확인해야 함.

### ① 미리캔버스 디자인허브 수익 인증 후기 (224450388309, 10/22) · 경험형
흐름: 경고 → 괄호 체류 유도 → 내 실적 숫자(100개 제출, 42개 리젝) → **스스로 묻기("얼마 벌었냐고요?")** → 한 박자 미룸("놀라지마세요") → 수익 공개 + 자조 → 대안 제시 → 내 과정 증거 사진 → 여운
- 첫 화면 6줄째: "보지 마세요" 경고 + 괄호로 "(끝까지보십쇼)" → **반대로 말해 붙잡기**
- 1/3 지점: 질문을 던지고 답을 3문단 미룸 → 엄지가 답 찾아 내려감
- 2/3 지점: 결과 공개 직후 "동전 줍는 게 낫다" 자조 → 웃겨서 계속 읽음
- 끝: "많관부" → 다음 글 예고 없이 관계로 닫음

### ② 홍콩 옥토퍼스카드 구매·충전·환불 (224448313227, 10/20) · 정보형
흐름: 한 줄 정의(티머니 비유) → 순서 예고 → 구매(HK$39 vs 200 비교) → **"끝까지 보세요"** → 노선도 → 요금표 → 공항 루트 → **판정 숫자(HK$109.4보다 싸면 표 따로)** → "귀찮으면 걍" 출구
- 3줄째: 낯선 것을 아는 것(티머니)에 붙임 → 이해 끝, 마음 편해짐
- 1/4 지점: "끝까지 보세요" + **무엇을 줄지(충전금·환불법)를 같이 말함** → 그냥 조르는 게 아님
- 2/3 지점: 계산을 "이 숫자보다 싸면 A, 비싸면 B"로 끝냄 → 독자가 자기 숫자를 대입함
- 결론 직후: "귀찮으면 걍 ㄱㄱ" → 출구를 열어줘서 오히려 신뢰

### ③ 홍콩 11월 날씨 옷차림 (224444798097, 10/17) · 답 먼저형
흐름: **첫 화면에 답(24~25도, 반팔+겉옷)** → 예고("행사부터, 초·중·말 이어서") → 30년 평균 → 작년 날짜별 → **중순 반전(27.4도→16.8도, 이틀에 10도)** → 코디 → 해 지는 시간 → 준비물
- 첫 화면: 답을 다 줬는데도 이탈이 적은 구조. 이유는 2/5 지점의 **"갑자기 뚝"** 반전 — 평균만 믿으면 추운 날이 있다는 것
- 구간마다 "~하더라고요", "덥겠어요ㅠㅠ" 같은 **감상 1줄** → 표·숫자 사이 숨 쉴 곳
- 단점: 제휴·자기 글 링크가 첫 화면에 끼어듦 (의뢰인은 안 씀, 베끼지 않음)

## B. 화재보험 초안 진단 (08 v1.2)

| 구간 | 계속 읽게 하는 것 | 이탈 지점과 이유 |
|---|---|---|
| 오프닝 따옴표 | 사장님 목소리로 시작, 좋음 | "11월 불조심 강조의 달" → 사람 말 바로 뒤에 **공문 냄새**. 누가 언제 들었는지 없음 |
| 결론 박스 | 답이 빨리 옴 | 한 문장에 두 정보(의무 + 따로) 54자 → 엄지가 멈추는 게 아니라 **건너뜀** |
| 판정표 | 10초 판정, 최고 장치 | **최대 이탈점.** "1층 20평 → 의무 없음 → 닫기". '의무 없음' 사장님을 붙잡는 문장이 0줄 |
| 의무보험만? | 1억 5천·10억 숫자 | 과태료 300만 원(제일 아픈 숫자)이 구간 끝에 묻힘 |
| 월세 가게 | "네, 불이 내 가게에서 났다면요." 대화 리듬, 좋음 | 바로 "~할 수 있습니다" 습니다체 + 기울임 풀이 2연속 → 교과서로 바뀜 |
| 집기 금액 | **비례보상 계산 = 이 글의 클라이맥스** | 질문 없이 표를 그냥 놓아서 "얼마 받았을까?" 하는 긴장이 안 생김 |
| 재조달가액 | — | 줄글 + "180일 서면" → **두 번째 이탈점**. 감상·장면 없음 |
| 옆 가게 | 짧아서 부담 없음 | 감정 0, 결말 없이 "넉넉하게" |
| Q&A·마무리 | 보험료 2만~6만 원은 안심 숫자 | 안심 숫자가 맨 뒤라 앞에서 겁먹고 나간 사람은 못 봄. "다음 글에서는" = v1.4 상투어 |

**사람이 쓴 글 같은가:** 정확한데 **아무도 안 놀라고 아무도 안 웃는다.** 기울임 풀이 7번이 같은 리듬으로 반복되고, 사람 냄새가 날 유일한 자리인 [경험] 2곳이 비어 있다. 지금 상태로는 "보험사 안내문을 쉬운 말로 바꾼 것"이다.

## C. 빼기 / 넣기 / 베끼기

**빼기**
- 기울임 용어 풀이 7연속 → 절반은 문장 속 풀이로. 같은 리듬이 기계 티의 1순위.
- "불조심 강조의 달" 오프닝 2번째 줄 → 시기 훅은 제목·태그로 충분, 첫 화면은 사람 말만.
- 결론 박스의 54자 한 문장 → 두 줄로 쪼갬. 박스 이름은 없어도 됨.
- 습니다체 문단 → 40~60대 사장님께 갑자기 공문 톤. 해요체 + "~더라고요"로 통일.
- 마무리 "다음 글에서는" → 독자 질문으로 바꿈.

**넣기**
- 표 바로 아래 **이탈 차단 1줄**: "의무 없음 칸이어도 닫지 마세요, 3번은 해당돼요" — 최대 이탈점을 막음.
- 클라이맥스 앞 **자문 + 지연**: "그래서 얼마 받았을까요?" → 독자가 추측하게 한 줄 → 표.
- 구간마다 **감상·감탄 1줄** ("이거 듣고 저도 놀랐어요" 같은 것) — 숫자 사이 숨 쉴 곳.
- 첫 화면 **"끝까지 보세요" + 무엇을 줄지** 1회 — 조르기가 아니라 약속.
- **출구 문장**: "복잡하면 이것 하나만" — 출구를 열면 믿고 남는다.
- 안심 숫자(의무보험 1년 2만~6만 원, 2022년 기준)를 두려움 숫자 바로 뒤로 → 겁먹고 나가는 것 방지.

**베끼기**
- 옥토퍼스의 **판정 숫자**: "가입 금액이 실제 가치의 80%보다 적으면 덜 받는다" → 사장님이 자기 집기 값을 대입하게.
- 홍콩 날씨의 **평균 → 반전**: 의무보험(모두의 답) → "근데 우리 가게는?"(반전) 구조로 글 전체를 짠다.
- 미리캔버스의 **스스로 묻고 한 박자 미루기**: 계산 결과 공개에만 1번 쓴다.
- 옥토퍼스의 **아는 것에 붙이기**: 구상 = "보험사가 대신 내고 사장님한테 청구서 보내는 것".

## D. 내가 이 주제를 쓴다면

**제목 3안** (검색어 1자 시작, 25~40자)
1. 가게 화재보험 꼭 들어야 할까? 2천만 원 들고 1,500만 원 받은 이유
2. 가게 화재보험 "건물주가 들었으니 괜찮죠?" 세입자가 물어줄 돈은?
3. 가게 화재보험 의무 대상 아니어도 챙길 2가지? 층·평수별 확인법

**뼈대 (소제목 순서)**
0. 첫 화면 (답 + 범위 + 끝까지 약속)
1. 우리 가게, 의무보험 대상일까? — 판정표 + 이탈 차단 1줄
2. 의무보험 있으면 다 나올까? — 4방향 표(손님○ 옆 가게○ 건물주✕ 내 집기✕) + 과태료 300만 원 + 안심 숫자
3. 월세인데 건물주 건물까지 왜 내가? — 장면 1개 + 계약 전 2문항
4. **3천만 원 손해, 얼마 받았을까?** — 자문 → 지연 → 표 → 80% 판정 기준 (클라이맥스, 글의 60% 지점)
5. 새것 값으로 받으려면? — 체크박스 3칸 (특약 / 다시 사기 / 180일 서면)
6. 옆 가게로 번지면 전부 내 돈? — 안심 + 단서
7. Q&A 2개 + 출구 마무리

**첫 화면 전문**
> "건물주가 보험 들어놨으니까 저는 괜찮죠?"
> 사장님들한테 진짜 자주 듣는 말이에요.
> 근데요, 그 보험은 건물주 재산 지키는 거예요.
> 불이 우리 가게에서 시작되면
> 손님, 옆 가게, 건물 값까지 사장님 몫이 될 수 있어요.
>
> 답부터 드릴게요.
> 층·평수가 기준에 맞으면 의무보험은 법으로 들어야 해요.
> 그리고 의무보험이 있어도 내 집기랑 건물 값은 따로예요.
>
> 아래에 우리 가게가 대상인지 10초 판정표,
> 3천만 원 손해 났는데 1,500만 원만 받은 계산까지 넣었어요.
> (대상 아니라고 나와도 그 계산은 끝까지 보세요. 진짜로요.)

**궁금증 장치 배치**
| 구간 | 장치 |
|---|---|
| 0 | 결과 숫자만 먼저 공개하고 이유는 미룸 + 괄호 체류 유도 |
| 1 표 아래 | "'의무 없음'이세요? 그럼 오히려 4번이 사장님 얘기예요" |
| 2 끝 | 4방향 중 ✕ 2칸 → "건물주 건물은 누가 물어주냐면요" 다음 소제목으로 연결 |
| 3 | "네, 내 가게에서 났다면요" 짧은 반박 + 청구서가 오는 장면 |
| 4 | "얼마 받았을까요? 2천? 3천?" → 표 → "1,500이에요" + 감탄 1줄 |
| 5 | 체크박스 → 엄지가 칸마다 멈춤 |
| 7 | 출구 + 독자 되묻기 |

**마무리:** 출구 → 1인칭 → 되묻기.
"복잡하면 하나만 하세요. 우리 가게 대상인지, 갱신일이 언제인지." → [경험: 신혁 님이 실제로 확인해 본 한 줄] → "그럼 갱신일 하루 지나면 얼마 붙는지 궁금해지시죠?" (N-c, '다음 글' 단어 없이). 약관 "보상하지 않는 손해" 문장은 출구 바로 위에 유지.

## E. 정답을 앞에서 말해도 계속 읽게 만드는 내 방식

1. **답은 '평균', 독자는 '예외'라는 걸 보여준다.** 홍콩 날씨처럼 "보통은 이래요"를 주고 "근데 이런 날이 있어요"로 꺾는다. 화재보험에선 "의무보험 들면 끝" → "근데 2칸은 안 나와요".
2. **답은 주되 결과 숫자의 이유는 미룬다.** "1,500만 원만 받았다"는 앞에, "왜"는 60% 지점에. 답은 줬으니 낚시가 아니고, 이유는 궁금하다.
3. **"끝까지 보세요"는 무엇을 줄지와 같이 말한다.** 약속 없는 조르기는 이탈을 부른다.
4. **출구를 연다.** "귀찮으면 이것만." 독자가 나가도 된다고 느끼면 오히려 남는다.
5. **숫자 사이에 감정 한 줄.** 사람은 정보가 아니라 같이 놀라는 사람 때문에 내린다.

## F. 다른 블로거들과 부딪힐 입장

- **양보 못 함:** **[경험]이 비거나 말맛(감상·되묻기)이 0인 구간이 있으면 발행하지 않는다.** 자동 발행이라도 구간마다 사람 목소리 1줄은 필수. 표·번호 항목만 채운 "만점 구조"(제철건강식)도 사람이 없으면 이웃이 안 생긴다.
- **양보할 수 있음:** 내 블로그의 ㅋㅋㅋ·반말·오타 섞인 강한 말투. 40~60대 사장님 대상이니 감탄은 "진짜요", "놀랐어요" 수준으로 낮추고, 검색어 나열 제목(내 블로그 감점 요인)도 버린다. 지침의 '얼굴 회전' 규칙은 받아들이되, **말버릇(해요체 + "~더라고요" + 되묻기)은 고정**하자고 주장한다 — 사람이 보이려면 목소리는 매번 같아야 한다.
