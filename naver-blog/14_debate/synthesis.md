## 5. 남은 입장 차 (채택 안 된 쪽의 주장, 기록용)

- **Franky (I6):** 심장을 3번째로 올리면 뒤가 빈다. → 판별 구간과 FAQ가 후반을 받치므로 위험을 낮게 봄. 독립 심사에서 후반 이탈이 지적되면 4번째로 되돌린다.
- **으너니 (I9):** 감상·되묻기를 구간 절반 이상. → 채택 안 함. 대신 첫 줄 독자 말, 진정 문장, 경험 2곳으로 목소리를 확보.
- **끌림·김주부 (I2):** 훅 3편에 1편. → 다수결로 매 편. 훅 종류 회전으로 반복 우려를 해소한 것을 근거로 함.
- **제철건강 (I3):** 숫자 훅 + 하위 검색어 꼬리 제목. → T6(나열) 감점 우려로 제외.

## 6. 왜 이 구조가 "공감 많이 받은 글"과 구조적으로 같은가

토론에서 공감 수가 확인된 유일한 표본은 끌림 정보글 4편(공감 107 / 72 / 55 / 34)이다. 채택 구조를 그 흐름에 대 보면:

| 끌림 공감 상위 글 흐름 | 채택 구조 |
|---|---|
| 첫 화면 2문장: 답 + 범위 예고 | 1줄 독자 말 → 2줄째 답 → 범위 예고 |
| 번호 질문형 인용구 소제목 4~6개 = 하위 검색어 | 번호 질문형 소제목 6개 |
| 구간: 답 1줄 → ▶ 3~4개 → 근거 → 경계 문장 | 굵은 답 → 표·▶·○✕ → 설명 → 경계·다리 문장 |
| 예외 FAQ로 닫음 | 판별 자가점검 → FAQ(마지막 Q가 다음 질문) |
| 마무리 2문장 (정리 + 행동) | 한 줄 원칙 + 할 일 |

추가로 들어간 것(공감 표본에 없던 것): 따옴표 독자 말 첫 줄(Franky·으너니), ✓ 이탈 차단(김주부), 자문→공개 지연(으너니), 진정 문장(김주부), 판별 체크(제철건강).

한계: 공감 수는 끌림 4편, 김주부 1편(공감 6)만 확인됐다. 나머지 3곳은 모바일 본문에 수치가 표시되지 않았다. 끌림 공감에는 이웃 2만 명 품앗이 몫이 섞여 있다(끌림 본인 단서).
