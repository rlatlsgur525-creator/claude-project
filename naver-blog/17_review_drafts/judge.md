# 심사 결과 — 네이버 리뷰 삭제 3편

심사 기준일 2026-10-24 · 가상 독자: 전주 40~60대 식당·카페 사장님, 모바일, '네이버 리뷰 삭제' 검색 유입
비교 기준: 끌림(jini4998) '18개월 아기 발달은?' (공감 107)

## 0. 기준 글 구조 (공감 107)

1. 첫머리 2문장에 바로 답 ("~살펴보면 돼요") → 주의점 1문장. 범위 예고 없음
2. 번호 붙은 **정보 질문** 소제목 4개 ("~무엇이 좋을까요?")
3. 섹션마다 같은 틀: 답 1문장 → ▶ 3줄 → 기관 출처 문단("CDC는 ~안내해요") → 실용 팁 1문단
4. 표·체크리스트·사례·1인칭 없음. 섹션당 모바일 한 화면 남짓
5. 자주 묻는 질문 3개 → 정리 2문단 ("~기준으로 골라보세요") → 해시태그 7개

## 1. 편별 판정

### A · 사장님이 주인공 (StoryBrand)

**① 스크롤 — 통과** (높음 0 / 중간 2)

| 화면 | 위험 | 근거 |
|---|---|---|
| 도입 | 낮음 | "사흘을 못 주무셨대요"로 사람 이야기가 걸림 |
| 1번 | 낮음 | 리뷰 원문 ▶, 끝에 이어지는 질문 |
| 2번 | 중간 | 4행 표에 "스마트플레이스 → 리뷰 주소…" 같은 긴 칸. 모바일에서 10줄 넘게 늘어남 |
| 3번 | 낮음 | 의견·추측·사실 표는 내 리뷰와 바로 비교됨 |
| 4번 | 중간 | 체크 4줄 뒤 규칙 3개가 한 문단에 몰림 (82줄) |
| 5번 | 낮음 | 답글 예문, 바로 따라 쓸 수 있음 |
| FAQ·끝 | 낮음 | 짧음 |

**② 답 먼저 + 궁금증 — 통과.** 첫 화면에 "손으로는 못 지우고, 신고 길 두 개"라는 답이 있다. "그 사장님은 어떻게 됐나"가 남는다. 다만 이 궁금증에 끝까지 답하지 않는다. 리뷰가 지워졌는지 글 어디에도 없다.

**③ 구조 유사성 — 미달** (다름 3개)
- 다름: 소제목이 정보 질문이 아니라 사례 질문 ("사장님은 왜 그 리뷰에…")
- 다름: 섹션 틀이 매번 바뀜 (▶ / 표 / 표 / 체크 / 인용)
- 다름: 마무리에 정리 2문단 대신 사장님 말 한 줄
- 같음: 첫머리 답, 기관 출처 문단, FAQ 3개, 해시태그
- 추가: 섹션 끝 이어지는 질문, 1인칭 사례

**④ 신뢰·호감 — 4/5**
- 증빙 모으기부터 답글 다듬기까지 함께한 사람으로 보이고, "없는 잘못을 인정하는 사과는 아님" 같은 선이 믿음을 준다.
- 결과를 말하지 않아 실력은 증명되지 않고, 따뜻함만 남는다.

### B · 다른 사장님이 독자 (PAS)

**① 스크롤 — 통과** (높음 0 / 중간 2)

| 화면 | 위험 | 근거 |
|---|---|---|
| 도입 | 낮음 | "그마저도… 대부분 안 내려가요" 뒤에 "그냥 둬야 할까요?" |
| 1번 | 낮음 | 할 수 있는 것/없는 것 ▶. "돈을 내면 지워 준다는 연락"이 걸림 |
| 2번 | 낮음 | '그냥 두면 손해'라는 PAS의 핵심. "한 번 쏠 때 제대로" |
| 3번 | 중간 | 5행 표가 화면 기준(5~6줄)을 넘음. 내 리뷰를 찾는 재미는 있음 |
| 4번 | 중간 | 3번 바로 뒤에 또 4행 표. 기준·처리 정보가 3번·FAQ와 겹침 |
| 5번 | 낮음 | 사실·마음·확인 답글 틀 |
| FAQ·끝 | 낮음 | "숫자 두 개" 정리가 깔끔함 |

**② 답 먼저 + 궁금증 — 통과.** 답(못 지움, 창구 둘)과 함께 "신고했다가 오히려 손해 보는 경우"를 예고한다. 사장님이 가장 겁내는 '역효과'를 건드려서 계속 읽게 된다. 셋 중 가장 강하다.

**③ 구조 유사성 — 통과** (다름 1개)
- 다름: 섹션 틀이 ▶ 대신 표로 바뀌는 곳이 두 군데 (3·4번)
- 같음: 첫머리 답, 정보 질문 소제목, 섹션 첫 문장 답, 기관 출처 문단("권리보호센터는 ~밝혀요"), FAQ 3개, 정리 마무리, 해시태그
- 추가: 이어지는 질문, 사례 1줄

**④ 신뢰·호감 — 3/5**
- 정확하고 정리가 잘 됐다. "돈 내면 지워 준다" 업자를 경계하게 하는 문장은 사장님 편이라는 인상을 준다.
- 사람은 한 줄만 나온다 ([경험] 빈칸). '이 사람한테 묻고 싶다'보다 '잘 정리된 글'에 그친다.

### C · 상담 일지 (Before→After→Bridge)

**① 스크롤 — 미달** (높음 0 / 중간 3)

| 화면 | 위험 | 근거 |
|---|---|---|
| 도입 | 낮음 | "30일." 숫자로 시작하는 훅이 강함 |
| 1번 | 낮음 | "당장 지워 주세요", 사장님 말 그대로 |
| 2번 | 낮음 | 3행 판정 표, 짧음 |
| 3번 | 중간 | 메뉴 경로 체크 4줄이 화살표 나열이라 40~60대에게 읽기 벽. 주민번호 팁이 일부 구제 |
| 4번 | 낮음 | 같이 소리 내 읽은 장면 |
| 5번 | 낮음 | 날짜 표로 결과를 보여줌. 이 글의 정점 |
| 6번 | 중간 | 결과를 본 뒤라 긴장이 풀림. 2·3번 내용을 체크리스트로 반복 |
| FAQ | 중간 | 6번 직후 세 번째 반복. 이탈 구간 |

**② 답 먼저 + 궁금증 — 통과.** "직접 못 지움, 통과해도 30일 게시중단"이라는 답이 있고, "30일 뒤 결과"라는 분명한 궁금증이 남는다. 5번에서 그 궁금증에 답한다. 다만 제목의 "잘못 신고하면 끝?"은 본문에서 한 문장(96줄)으로만 다뤄서 약속보다 작다.

**③ 구조 유사성 — 미달** (다름 3개)
- 다름: 시간순 일지 구조 (기준 글은 주제별 질문 나열)
- 다름: 소제목 절반이 사례 질문 ("첫날, 사장님은 뭘 원하셨을까?")
- 다름: 마무리가 정리 없이 질문 1줄
- 같음: 첫머리 답, 기관 출처 문단, FAQ 3개, 해시태그
- 추가: 6번 따라 하기 체크, 결과 날짜 표

**④ 신뢰·호감 — 4/5**
- 접수부터 삭제까지 30일을 같이 버틴 사람이다. 주민번호 뒷자리 가리기 같은 실무 디테일은 직접 해 본 티가 난다.
- "저도 처음엔 지우는 버튼이 있을 줄"(32줄)은 공감은 사지만, 전문가로 보이는 데는 손해다.

## 2. 3편 비교

### 가장 잘 맞는 상황
- **A**: 이웃·신뢰 쌓기용. 감정 이입은 되지만 검색자가 원하는 결과가 빠졌다.
- **B**: 검색 유입용. 기준 글과 구조가 가장 가깝고, 표 3번 하나로 바로 자가 진단이 된다.
- **C**: 상담 문의 유도용. "30일을 같이 보내 주는 사람"이라는 그림이 문의로 이어지기 가장 쉽다.

### 매일 반복하기 가장 쉬운 틀: B (PAS)
- 실제 사례가 한 줄만 있어도 된다. A·C는 매 편마다 실제 상담 하나를 처음부터 끝까지, 결과까지 갖춰야 한다. 그래서 머리말에도 "실제 사례로 바꾸기 전 발행 금지"가 붙어 있다. 매일 쓰기엔 재료가 모자란다.
- 문제 → 방치 시 손해 → 해결 → 정리라는 뼈대를 어느 제도·상품 주제에나 끼울 수 있고, 기준 글의 질문형 섹션 틀과도 바로 겹친다.
- 권장 운영: 평소엔 B로 쓰고, 실제 사례가 생긴 날만 C로 쓴다.

### 네이버 제도 설명 점검
권리보호센터 고객센터와 MY플레이스 고객센터 문서를 대조했다. 1주 처리, 결과 개별 안내 없음, 30일 뒤 복원, 같은 사유 재신고 불가, 요청자가 당사자로 안내됨, 방송미디어통신심의위원회 명칭은 모두 맞다.

| 편·줄 | 문장 | 문제 |
|---|---|---|
| A 14 | "의견이냐 사실 주장이냐에서 갈려요" | 욕설·개인정보 노출은 의견이어도 리뷰 신고 대상이다. 첫 문장이라 기준을 하나로 잘못 심을 수 있다 |
| B 15 | "신고하는 길 두 개만 있어요" | '만'은 틀린 말이다. 리뷰어 신고(MY플레이스), 방심위 심의, 법원·합의도 있다. 자기 FAQ(114줄)와도 어긋난다. A 15도 정도는 덜하지만 같은 문제 |
| B 76 ↔ 81 | "같은 ⋮ 메뉴에 있지만" / 표 "리뷰 화면 ⋮" vs "스마트플레이스 ⋮" | 한 섹션 안에서 위치 설명이 서로 다르다 |
| A 79, B 83, C 88·94 | "이의신청 없으면 30일 뒤 삭제" | 권리보호센터 안내는 복원 조건만 명시하고 '삭제'를 확인할 문구는 없다. "계속 가려진다(게시중단 유지)"로 쓰거나 근거를 확인해야 한다 |
| A 49, B 82 | "검토 후 30일 게시중단" | 법(정보통신망법 44조의2)상 임시조치는 "30일 이내"다. 네이버 운영은 30일 뒤 복원이라 큰 오류는 아니지만 "최대 30일 가려짐 → 그 뒤 결정"이 더 정확하다 |
| C 10 | 제목 "잘못 신고하면 끝?" | 반려된 신고는 다시 할 수 있다. '끝'은 이의신청으로 복원된 뒤 같은 사유로만 해당한다. 낚시성 과장이다 |
| A 115, B 114, C 124 | "방심위 심의를 신청하는 길" | 맞다. 네이버는 당사자 합의와 법원 판단도 함께 안내하니 한 마디 덧붙이면 좋다 |

### 편마다 고칠 점 1순위
- **A**: 결과를 말할 것. 5번 뒤나 마무리에 "30일 뒤 리뷰는 ○○됐어요" 1줄을 넣고, 기준 글처럼 정리 2문단으로 닫는다. 지금은 검색자가 가장 알고 싶은 답이 빠져 있다.
- **B**: 3·4번 표 두 개를 하나로 합칠 것. 4번은 ▶ 3줄(기준·처리·그 뒤)로 바꾸고, 76줄의 '같은 메뉴' 모순과 15줄의 '만'을 지운다. 연속 표 화면이 이 글의 유일한 이탈 구간이다.
- **C**: 5번 결과 뒤를 줄일 것. 6번 체크리스트를 FAQ 자리로 흡수하고, 마무리를 질문 1줄 대신 정리 2문단으로 바꾼다. 제목의 "끝?"은 "30일 동안 일어나는 일"처럼 본문이 실제로 지키는 약속으로 고친다.

## 3. 요약
- A: ①통과 ②통과 ③미달 ④4점 — 이웃용. 결과 누락이 치명적
- B: ①통과 ②통과 ③통과 ④3점 — 검색용, 매일 쓰기 가장 쉬움
- C: ①미달 ②통과 ③미달 ④4점 — 문의 유도용. 결과 뒤 반복으로 이탈
