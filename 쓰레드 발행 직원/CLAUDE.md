## 지켜야 할 것

- 사용자가 승인한 글만, 승인한 문구 그대로 발행한다.
- 사용자가 "B로 가자"처럼 방향을 고르면 기획검토 탭의 그날 행 선택 칸(K열)에 적는다. 직접 아이디어를 주면 선택 칸에 "직접", 내 지시 칸(L열)에 내용을 적는다.
- 기획은 아직 완성되지 않았다. 방향은 사용자가 정하고, Claude는 근거와 선택지를 준다.
- 사용자는 토큰 낭비를 싫어한다. 답은 짧게, 이미 정한 것은 다시 묻지 않는다.
