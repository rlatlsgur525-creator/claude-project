# 맛집 게시물 작업실

사진을 넣으면 필터, 표지 후보 5개, 카드뉴스, 하이라이트 릴스, 캡션·해시태그까지 만들어 게시 직전 상태로 준비합니다. 두 가지 방법으로 쓸 수 있습니다.

## 방법 1. Claude에게 맡기기 (추천)

1. 채팅에 사진을 보내며 역할을 말합니다. 예: **"썸네일은 이거랑 이거, 나머지는 이거 쓸 거야"**
   - 썸네일 위 = 가게 입구·간판, 썸네일 아래 = 대표 메뉴 클로즈업
   - 지글지글 끓는 짧은 영상이 있으면 같이 보내 주세요(릴스에 끼워 넣습니다).
2. Claude가 상을 다 차려 둡니다. 필터, 표지 5개, 캡션까지 만든 뒤 작업실 주소를 드립니다.
3. 작업실에서 **표지 하나 고르고 캡션만 확인**한 뒤 [확정]을 누릅니다. 채팅으로 "B로 해줘"라고 해도 됩니다.
4. **"예약 걸어줘"**: Claude가 시간을 확인한 뒤 Uplika로 인스타에 예약합니다.

## 방법 2. 작업실에서 직접 하기

PC에서 아래처럼 켜면 브라우저에 작업실이 열립니다. Claude에게 "작업실 열어줘"라고 해도 됩니다.

```bash
python studio/matzip/review.py
```

| 단계 | 하는 일 |
| --- | --- |
| 위쪽 | 게시물 고르기, **+ 새 게시물** (가게 이름·지역·대표 메뉴) |
| 1. 사진 | [사진 올리기]. 사진마다 **표지 위(가게 입구) / 표지 아래(대표 메뉴) / 본문 / 안 씀**을 고르고, 본문은 ◀ ▶ 로 순서를 바꿉니다 |
| 2. 필터 | 맛있게 기본 / 쨍하고 선명하게 / 필터 없음, 강도·밝기·따뜻함·색 진하게·선명함 슬라이더. 바로 미리 보이고, [누르는 동안 원본]으로 비교합니다. 미리보기를 누르면 그 지점이 카드 가운데로 옵니다 |
| 3. 표지 문구 | 가게 이름, 지역, 대표 메뉴, 한 줄 문구, 말풍선 2개. **[대괄호]** 는 노랑 강조 |
| 4. 표지 고르기 | [표지 5개 만들기] 후 하나를 누릅니다 (30초쯤) |
| 5. 캡션 확인 | 캡션·해시태그를 고치고 [이 표지로 확정하고 릴스 만들기] (1분쯤) |

- 고친 내용은 자동 저장됩니다.
- 표지를 만든 뒤 사진·필터·문구를 바꾸면 [표지 5개 만들기]를 다시 눌러야 반영됩니다. 화면에 노란 안내가 뜹니다.
- 아이폰 사진이 안 올라가면 카메라 설정의 형식을 '가장 호환성 높은'으로 바꾸세요(HEIC는 안 받습니다).

## 표지 5종

| | 이름 | 느낌 |
| --- | --- | --- |
| A | 불꽃 콜라주 | 사장님 기본. 위 입구 + 아래 메뉴, 큰 노랑 메뉴 이름, 불꽃, 붓띠, 말풍선 |
| B | 하단 큰 자막 | 메뉴 사진이 주인공, 아래 굵은 흰 자막 두 줄 |
| C | 마커 간판 | 빨강·검정 마커 글씨로 가게 이름을 크게 |
| D | 띠 분할 | 위 입구 + 아래 메뉴를 검정 띠로 나누고 띠 안에 노랑 제목 |
| E | 말풍선 후기 | 큰 말풍선 한 줄평 + 아래 위치 붓띠 |

나머지 장은 글자 없이 필터 입힌 사진만 들어갑니다. 반응이 큰 맛집 게시물들이 쓰는 방식입니다. 릴스는 표지 → 사진을 확대·이동하며 빠르게 넘기는 하이라이트입니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `review.py` | 게시물 작업실 (http://127.0.0.1:8770). `/edit` 은 예전 고급 편집(장마다 글자 위치·색) |
| `make_post.py` | brief.json → 필터·표지 후보·카드뉴스·캡션. `--pick B` 로 표지 확정 + 릴스 |
| `look.py` | 맛있게 필터 (웹 [맛있게 필터](https://claude.ai/artifact/9oMAywXfDtRBFxExc1xjoe)와 같은 결과, `filter.html` 이 그 원본) + 슬라이더 조절 |
| `covers.py` | 표지 템플릿 5종 |
| `render.py` | 카드(1080×1350)와 하이라이트 릴스(1080×1920) |
| `PLAYBOOK.md` | 인기 게시물 비교, 형식 기준 |
| `posts/<날짜-가게>/` | 게시물 하나. `photos/` 원본, `photos_f/` 필터본, `brief.json` 설정, `out/` 결과 |
| `../fonts/` | 한글 글꼴 27종 (모두 OFL, 상업적 이용 가능) |

## 핸드폰으로 쓰기

`--phone` 을 붙여 켜면 핸드폰 주소가 찍히고 `phone_url.txt` 에도 저장됩니다. 핸드폰에서 사진 올리기까지 됩니다.

```bash
python studio/matzip/review.py --phone
```

- 핸드폰과 PC가 **같은 와이파이**에 있어야 하고, PC가 켜져 있어야 합니다.
- PC의 와이파이가 **공용 네트워크**로 되어 있으면 Windows 방화벽이 막습니다. 믿을 수 있는 와이파이라면 개인 네트워크로 바꾸고, 방화벽 창이 뜨면 **개인 네트워크만** 허용하세요.
- 주소 끝의 `k=` 비밀 키가 없으면 열리지 않습니다. 켤 때마다 키가 바뀝니다.
