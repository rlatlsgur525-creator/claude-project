초안을 쓸 때 이 문서를 기준으로 하고, 몇 달에 한 번 인기 게시물을 다시 보고 갱신합니다.

게시물 형식은 세 가지입니다. post.json 의 `"style"` 로 구분합니다.

| style | 느낌 | 언제 |
| --- | --- | --- |
| `thumb` (**기본**) | 사장님 표지(입구+시그니처 콜라주, 썸네일 장식) + 나머지는 필터 입힌 사진만 + 하이라이트 릴스 | 2026-10-23 사장님이 정한 기본 |
| `info` | taste.jeonju 같은 정보형. 표지 고딕 제목 | 참고용. 그대로 쓰면 "상위글 따라한 느낌"이 난다는 피드백이 있었다 |
| `hand` | 장마다 손글씨 문구·화살표·말풍선 | 개인 리뷰 감성이 필요할 때 |

**결론**
- 반응이 가장 큰 게시물일수록 **표지 한 장만 글자**를 넣고, 나머지는 **잘 찍고 필터 입힌 사진**만 씁니다. 영상 조각을 섞기도 합니다.
- 장마다 글자를 넣은 치히로 게시물은 비교한 게시물 중 반응이 가장 낮았습니다. 다만 2023년 게시물이라 단순 비교는 어렵습니다.
- 표지는 사장님 스타일로 차별화합니다. 입구 간판과 시그니처 메뉴를 한 장에 넣으면 가게 인지와 메뉴 훅이 동시에 됩니다. 이렇게 만든 곳은 비교 대상 중에 없었습니다.

## thumb 형식 (기본)

**장 구성** (8~12장)
1. **표지 콜라주**: 위는 가게 입구·간판(`top_image`), 아래는 시그니처 메뉴 클로즈업(`image`)입니다.
2~N. **글자 없는 사진**: 상차림 → 시그니처 클로즈업 → 집어 올린 샷 → 쌈·조합 → 사리·볶음밥 → 반찬 → 손님 많은 내부(얼굴 흐림) → 외관 순서입니다. 필터는 맛있게 필터로 입힙니다.
- `info_slide: false` 로 둡니다. 주소와 시간은 캡션에 씁니다.

**표지 설정값** (숙이네 밥상 초안 1장 참고)
- 장 옵션: `top_image`, `top_crop`(사진에 다른 글씨가 있으면 잘라 냄), `top_focus`, `split: 0.46`, `feather: 0.12`, 메뉴 사진 `focus` 는 음식이 아래쪽에 오도록 맞춥니다.
- 요소는 뒤에서 앞 순서로 놓습니다.
  - `flame` 은 제목 왼쪽 뒤에 둡니다.
  - 📍`pin` + `"지역 맛집"` 빨간 붓띠(`bg: "band"`, `font: "bold"`)를 왼쪽 위에 둡니다.
  - 제목 3조각을 따로 놓습니다. "지역"은 흰색 크기 130, "**[메뉴]**"는 노랑 `#FFE600` 크기 200~230, "맛집"은 흰색 크기 110입니다. 모두 `font: "bold"`, `stroke` 10~13 검정, `rotate: -6` 입니다.
  - 부제는 `font: "round"`, 빨간 붓띠, `sparkle: "both"`, 강조 단어 노랑입니다.
  - 말풍선 2개(`bg: "bubble"`, 빨간 거친 테두리)와 고리 화살표(`loop: true`)를 음식 쪽에 둡니다.
- 메뉴 이름이 길면 "[메뉴]" 크기를 줄여 폭 85%를 넘지 않게 합니다.

**하이라이트 릴스** (`--reel`, 승인 시 자동)
- 표지 카드를 `cover_seconds`(2.4초) 동안 보여 줍니다.
- 이어서 글자 없는 사진을 9:16 화면 가득 `seconds_per_slide`(1.6초)씩 넣습니다. 확대, 이동, 축소, 위로 이동을 번갈아 씁니다.
- 사장님이 찍은 영상이 있으면 `reel.clips` 에 `{"file": "clips/a.mp4", "start": 초, "len": 초, "after": 장번호}` 로 끼워 넣습니다. 지글지글 끓는 장면이나 집게로 드는 장면이 좋습니다.

**캡션**: hand 형식 템플릿(아래)을 씁니다. 말투는 사장님 기존 캡션("~찾는다면 여기;;", "국룰", "친구 태그하기💌")을 따릅니다.

## info 형식 (taste.jeonju 분석, 참고용)

**장 구성** (10장)
1. **표지**: 대표 메뉴 클로즈업이나 상차림 전체샷. 글자는 이 장에만 넣습니다.
2~8. **메뉴 사진만**: 상차림 → 시그니처 클로즈업 → 집어 올린 샷 → 반찬 → 사이드 순서입니다. 글자, 화살표, 스티커를 넣지 않습니다.
9~10. **내부 → 외관·간판**: 마지막 장은 간판이 보이는 외관으로 끝냅니다. 정보 카드는 넣지 않습니다(`info_slide: false`). 정보는 캡션에 씁니다.

**표지 A: 아래 제목형** (예: 숙이네 밥상 초안 1장)
- 사진 아래 40%를 진하게 어둡게 합니다: `shade: "bottom"`, `shade_amount: 250`, `shade_start: 0.3`.
- 어두운 부분에 반짝이 가루를 뿌립니다: `{"type": "dust", "from": 0.58, "to": 1, "count": 70}`.
- 위에서 아래로 세 덩어리를 놓습니다.
  - 작은 한 줄: 메뉴 조합이나 계절감을 담고 `!!` 로 끝냅니다. `font: "sub"`, 크기 38~44, 흰 알약 배경(`bg: "box"`, `bg_color: "#FFFFFF"`, `bg_opacity: 0.93`, `color: "#111111"`, `shadow: false`)이거나 배경 없는 흰 글씨입니다.
  - 제목 1줄: `font: "title"`, 크기 110~120, `shadow: "strong"`, 강조 단어는 민트 그라데이션 `hl_grad: ["#EFFFF9", "#8EF0CF"]` 입니다.
  - 제목 2줄: 같은 글꼴에 크림 노랑 그라데이션 `hl_grad: ["#FFFDF0", "#FFDD7A"]` 를 씁니다.
- 제목 한 줄은 공백 포함 **10자 안팎**입니다(1080px 폭에 크기 116 기준).

**표지 B: 집중선형** (숙소·핫플·이벤트성 메뉴에 어울림)
- `dim: 0.45` 로 사진 전체를 어둡게 하고 `{"type": "burst", "inner": 0.45, "color": "#FFFFFFB0"}`, `dust` 를 깝니다.
- 가운데 정렬로 4~5줄을 쌓습니다: `@@친구에게 말하듯 한 줄..` → `((지역 OO 가면))` → `무조건 가야 할` → 주황 알약 줄(`bg: "box"`, `bg_color: "#FFB45E"`, `color: "#1A1A1A"`) → `[메뉴] 맛집이라고!?`

**제목 말투**: "방송에 나온 찐맛집!", "OO동 보양식 끝판왕", "전주 신선한 제철회 / 이자카야 감성 핫플!", "여기로 정착>>" 처럼 단정형·과장형으로 씁니다. 1인칭 감상은 넣지 않습니다.

**사진 색감**: 맛있게 필터의 **전주맛집 st** 를 씁니다. 흰 접시는 하얗게 두고 대비, 채도, 질감을 강하게 줍니다.

**캡션 템플릿 (info)**

```
{이모지}{표지 제목 그대로}{이모지}

{지역·위치} {한 줄 소개}
‘{가게명}’{이모지}

여기 시그니처는 {메뉴}인데!!🤤
{맛 디테일 2줄}🔥

{반찬·사이드·추가 메뉴 2~3줄}✨

{누구랑 가기 좋은지 / 좌석·룸·주차} {행동 유도: 달려가자!! / 여기로 가자💗}

📍 {가게명}
📍 {주소}
{선택: 💌 예약 문의 / 📞 전화}

#{지역}맛집 #{동네}맛집 #{가게명} #{지역}{메뉴} #{상황: 전주회식장소, 전주데이트}
```
- 해시태그는 **5개**입니다. 가게명 해시태그를 꼭 넣습니다.
- 줄은 18~22자에서 끊고, 문단마다 이모지 1~2개를 붙입니다.

## 글꼴 고르는 법

| 용도 | 키 | 비고 |
| --- | --- | --- |
| 표지 큰 제목 (info) | `title`, `title2` | 프리텐다드 블랙·엑스트라볼드 |
| 표지 작은 한 줄 | `sub` | 프리텐다드 세미볼드 |
| 레트로·간판 느낌 제목 | `gasoek`, `bold`, `dohyeon` | 노포, 고깃집, 백반집 |
| 귀엽고 통통한 포인트 | `bagel`, `round`, `dongle` | 디저트, 카페, 분식 |
| 독특한 포인트 | `gugi`, `sunflower`, `stylish`, `bwpicture` | 한 게시물에 한 번만 |
| 손글씨 (hand) | `hand`, `pen`, `brush`, `dokdo`, `eastsea`, `singleday`, `cute`, `poorstory`, `kirang`, `gamja`, `himelody`, `yeonsung` | `dokdo`·`eastsea` 는 거친 마커, `singleday`·`cute` 는 귀여운 펜 |

한 장에는 글꼴을 **최대 2종**만 씁니다. 굵은 제목체 하나와 작은 글씨체 하나입니다.

## 화면 문구 규칙

- 한 장에 **큰 문구 1개, 작은 문구 0~2개**만 넣습니다.
- 강조할 단어는 `[대괄호]`로 표시합니다. 노란색으로 칠해지는 단어로, 메뉴명이나 "밥도둑", "부드러운" 같은 핵심 감상어에 씁니다.
- 말투는 리뷰어 1인칭 감탄형입니다("~인정!", "~쏙-!", "착-!", "미쳤다..!").
- 음식 위에는 글자를 올리지 않습니다. 빈 배경, 테이블, 위쪽 여백에 두고 화살표로 음식을 가리킵니다.
- 사진 위 글자에는 이모지를 쓰지 않습니다(폰트 미지원). 하트는 장식 `heart`로, 위치 핀은 `pin`으로 넣습니다.
