# 포맷 설계도 — 장면 분석 결과 (2026-10-24)

`format_cards_1024.md`의 포맷 카드 5개에서 비어 있던 **초 단위 구조와 편집 수치**를 채운 문서다.
분석 도구: Higgsfield `video_analysis` (YouTube 링크 → 장면별 타임스탬프·화면·대사). 크레딧 차감 없음(270 → 270).
장면 구분은 도구 기준이라 실제 컷보다 굵게 잡힌 곳이 있다. 특히 한 장면이 30초 넘는 경우는 그 안에 작은 컷이 더 있을 수 있다.

**새로 알게 된 것 (카드 내용 수정)**
- **C는 "이야기"가 아니었다.** 대사 없이 8초짜리 실험 + 밈 리액션을 1초씩 번갈아 붙인 **반복 재생(루프)형**이다. 조회수 1,582만은 짧은 길이 → 여러 번 다시 보기에서 나온 것으로 보인다. 이식하려면 "라이벌 이야기 내레이션"이 아니라 "말 없는 8~10초 결과 공개 루프"로 만들어야 한다.
- **E는 이긴 쪽을 먼저 보여준다.** 결과를 끝까지 숨기지 않고, 1등을 가장 길게(12초) 먼저 설명한 뒤 나머지 둘을 짧게 처리한다.
- **A는 길다(2분).** 토크 한 장면을 30초 넘게 끊지 않는다. 컷 대신 이야기의 "추리" 과정이 시청을 붙잡는다.
- **B의 원본은 핵심 재료를 "이거"라고만 말한다.** 화면에 설탕과 액체가 나오지만 말로 짚지 않아 분노 댓글이 생겼다(카드의 분석과 일치). 우리는 반드시 이름을 말한다.

## B. 경고형 — "절대 ~하지 마세요" (25초, 컷 16개)

| 시간 | 역할 | 원본에서 한 것 | 미라클톡 이식 |
|---|---|---|---|
| 0~2초 | 훅: 명령 | "냉동고기 절대 냉장해동 하지마세요" + 그 행동을 하는 1인칭 화면 | "보험 해지 전에 절대 이것부터 하지 마세요" + 해지 신청 화면 |
| 2~3초 | 권위 출처 | "단골 정육점 사장님한테 말했더니" | "7년 동안 해지 상담하면서 본 건데요" |
| 3~8초 | 손해 | 냄새나고 퍽퍽해진다 | 다시 가입하면 보험료가 오르고, 그 사이 병력이 생기면 가입 자체가 어려울 수 있어요 |
| 8~9초 | 전환 | "그렇게 하면 안 된대요" | "그래서 순서를 바꿔야 해요" |
| 9~13초 | 대안 2단계 (각 1~2초) | 미지근한 물에 ○○ 넣고 10분 | ① 감액·납입유예 먼저 확인 ② 새 보험 승인 뒤 해지 |
| 13~16초 | 효과 | 빨리 녹고 육즙 유지 | 보장 공백 없이 정리 |
| 16~19초 | 직접 해봄 | "의심돼서 바로 해봤는데" | "실제로 상담에서 이렇게 하면" (사례는 익명·각색) |
| 19~22초 | 결과 증거 | "냄새 없고 촉촉" | 결과 한 줄 |
| 22~25초 | 행동 촉구 | "꼭 이 방법 쓰세요" | "해지 전에 이 두 가지만 확인하세요" |

- **편집:** 1.5초마다 화면이 바뀐다. 얼굴 없이 손과 물건만. 같은 행동을 다른 각도로 반복한다.
- **우리 규칙:** 핵심 재료(대안)는 **말과 자막 둘 다로** 이름을 밝힌다. 손해는 "~할 수 있어요"로 쓰고 단정하지 않는다.

## A. 현장 반전 썰 (2분, 장면 13개)

| 시간 | 역할 | 원본에서 한 것 |
|---|---|---|
| 0~5초 | 훅: 나와 현장 소개 | "강서고에서 10년 있었어요. 남고예요" + 학교 사진 삽입 |
| 5~15초 | 결핍 설정 | 새벽 6시 반 출근, 밤 12시 퇴근 → 연애할 기회가 없음 |
| 15~18초 | 사건 발생 | 운동장을 걷는 여자 두 명을 봄 (재연 B롤 3초) |
| 18~65초 | **추리 구간** | 학생들이 "누구지?" 추리 → "영양사 선생님이다!" → 농담으로 "번호 따와" |
| 65~95초 | 사건 확대 | 급식 줄 2,000명 앞에서 "선생님이 번호 따오래요!" → 일주일 동안 모름 |
| 95~104초 | 물건 공개 | 학생이 주머니에서 쪽지를 꺼냄 (B롤 2초) |
| 104~120초 | **연쇄 반전 + 결말 한 줄** | "통화한 김에 만날까요?" "만난 김에 사귈까요?" "사귄 김에 결혼할까요?" → "그렇게 결혼했습니다" |

- **편집:** 토크 장면이 길다(최대 33초 무편집). 10~30초마다 2~3초짜리 재연 B롤을 끼운다. 마이크와 칠판으로 "강의" 느낌을 만든다.
- **핵심 장치:** 결말 단어("결혼")를 마지막 한 문장에만 쓴다. 마지막 16초는 "~한 김에 ~할까요?"를 세 번 빠르게 반복하는 리듬이다.
- **미라클톡 이식:** 1분 안으로 줄이려면 추리 구간을 20초로 줄인다. 실제 고객 이야기는 익명으로 각색한다. 1테이크 토크 + 사진 2~3장 삽입이면 된다.

## C. 거인 대결 → "말 없는 결과 공개 루프" (8초, 컷 8개)

| 시간 | 화면 |
|---|---|
| 0~1초 | 실험 준비: 갈색 방울 두 개를 동시에 떨어뜨림 (분할 화면, 위에서) |
| 1~2초 | 리액션 A: 해골 마스크 인물이 천천히 고개를 돌려 카메라 응시 |
| 2~3초 | 개미가 다가옴 |
| 3~4초 | 리액션 B: 놀란 표정 |
| 4~5초 | 한쪽에 개미가 몰림 |
| 5~6초 | 리액션 A 반복 |
| 6~7초 | 결과: 한쪽만 개미로 덮임 |
| 7~8초 | 리액션 B 과장 → **처음으로 돌아가 반복 재생** |

- **편집:** 정확히 1초씩. 대사·자막 거의 없음. 경쾌한 음악 하나.
- **주의:** 리액션 얼굴은 남의 밈 영상이다(댓글에서 무단 사용 지적). 우리는 **같은 캐릭터 이미지를 직접 만들어** 쓴다.
- **미라클톡 이식:** "같은 100만 원, 10년 뒤" 막대 두 개가 자라는 화면 ↔ 캐릭터 리액션을 1초씩 번갈아 → 마지막에 숫자 공개. 가정 표기는 화면에 계속.

## D. 빌런 썰 (54초, 장면 10개)

| 시간 | 역할 | 원본에서 한 것 |
|---|---|---|
| 0~3초 | 훅: 의외의 일반화 | "영국 스타벅스 가면 매니저가 거의 다 한국인이에요" |
| 3~6초 | 판정 한마디 | "근데 그 매니저들이 엄청 꺼드럭대요" (얼굴 확대 + 찡그림) |
| 6~24초 | 상황 설명 | 신입은 영어가 서툴고, 영국 손님 주문은 복잡함 |
| 24~29초 | 맞장구 | 상대가 "첫날이면 당연히 긴장하죠" |
| 29~51초 | **흉내 재연** | 빌런 말투를 직접 따라 함 ("손님이 그거 달라잖아! 못 알아들었어?") ↔ 상대 웃음 |
| 51~54초 | 결론 한마디 | "사람 무시해!" → 해결 없이 끝 |

- **편집:** 고정 카메라 2인 대화. 말하는 사람으로 컷. 강조 순간에 얼굴 확대.
- **핵심 장치:** 해결이 없다. 시청자가 **댓글로 자기 경험을 이어 쓰게** 비워 둔다.
- **미라클톡 이식:** "보험 권유할 때 꼭 있는 유형" — 실존 인물이 아닌 "유형"으로만 흉내 낸다. 혼자라면 그래픽 캐릭터와 내레이션으로 대체한다.

## E. 비교 실험 (38초, 장면 6개)

| 시간 | 역할 | 원본에서 한 것 |
|---|---|---|
| 0~3초 | 셋업: 전부 한 화면에 | 모래 3종을 한 칸씩 담고 "동시에 시작합니다!" |
| 4~5초 | 동시 시작 장치 | 풍선 3개를 동시에 터뜨림 "잠시만요!" |
| 6~18초 | **1등을 먼저, 가장 길게** | 카사바 모래: 한 덩어리로 빠짐, 안 붙음 + 기행("맛도 전분 맛") |
| 19~23초 | 2번: 단점 위주 | 벤토나이트: 바닥에 들러붙어 청소 불편 |
| 24~30초 | 3번: 장단점 | 두부 모래: 잘 부서지지만 변기에 버릴 수 있음 |
| 31~38초 | 결론 + 실사용 | "이런 걸 찾는다면 카사바" + 큰 화장실에서 시연 |

- **편집:** 장면은 길지만 손 동작이 계속 움직인다. 결과를 숨기지 않는다.
- **미라클톡 이식 시 준법:** 원본의 마지막 "○○ 고르세요"는 상품 추천이라 그대로 쓰면 안 된다. **"이런 상황이면 이런 기준"**으로 바꾼다. 수익률 숫자는 가정 표기 + 코드 계산.
