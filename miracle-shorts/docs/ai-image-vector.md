# 이미지 모델 → 벡터 그림 (2026-10-26)

## 배경 (왜 하는가)
- 참고 사례(스레드 dalcomi20 "클로드 코드로 지식유튜브 만들기"): Claude가 혼자 그리면 SVG 기본 도형 조합이라 "머리는 동그라미, 몸통은 원통" 수준이 된다. 그래서 이미지 모델이 캐릭터 모양을 투명 배경으로 그리고 → Claude가 벡터로 따서 → 코드로 움직임·색을 맡는다.
- 벡터로 따면: 확대해도 선이 깨지지 않음, 색을 코드로 바꿔 팔레트(스타일) 고정 가능, 코드로 그린 배경과 질감이 맞음.
- 우리는 이미 Higgsfield(`miracle-fp`)로 캐릭터를 그리고 `make_cutouts.py`로 투명 PNG를 만든다. 빠진 것은 "벡터로 따기" 한 단계였다. 마스코트가 흑백 2색이라 거의 손실 없이 따진다.
- 원칙: 기존 렌더 결과는 바꾸지 않는다. 템플릿은 계속 PNG를 쓴다. 이번 작업은 도구 추가만 했다.

## 그 글과 비교

| 그 글 | 우리 | 상태 |
|---|---|---|
| 이미지 모델로 캐릭터시트 | Higgsfield `miracle-fp` | 이미 함 |
| 투명 배경 | make_cutouts.py | 이미 함 |
| 벡터로 따기 | `brand/mascot/vectorize.py` → `studio/library/mascot_svg/*.svg` | 이번에 추가 |
| 색 제한·스타일 고정 | `gfx.svg_img(name, h, ink, paper, edge)` | 이번에 추가(템플릿엔 아직 안 씀) |
| 장면 1개 먼저 → 나머지 | 스토리보드 '장면만 렌더' | 있음 |
| TTS는 대본 전체를 한 번에 | talk 템플릿 연결 때 적용 | 규칙만 |

## 작업 순서 규칙 (그 글에서 가져온 것)
1. **장면 1개 먼저:** 새 템플릿·새 그림체는 장면 하나만 렌더해 확인한 뒤 나머지를 만든다.
2. **TTS는 대본 전체를 한 번에** 만들고, 무음 감지(`pipeline.speech_spans`)로 줄마다 자른다. 줄마다 따로 만들면 톤이 바뀐다.
3. **스타일 먼저 고정:** 팔레트(잉크·바탕·강조 1색)를 정하고 모든 장면이 그 안에서만 색을 쓴다.
4. **AI는 모양, 코드는 움직임.** 영상 생성 모델은 꼭 필요한 곳에만 쓴다(크레딧).

## 확인 결과 (2026-10-26)
- `make_cutouts.py`의 배경 판별을 `bg_mask()`로 분리 → `raw/stop.png` 변환 결과가 바꾸기 전과 픽셀까지 같음.
- `vectorize.py` → point·stop·surprised·think·thumbsup·wave.svg 6개(77~111KB).
- **PNG와 크기·테두리 맞춤 (2026-10-26):** vectorize.py가 make_cutouts와 같은 기하(실루엣 ±12px → 높이 1400 축소 배율 → 바깥 여백 STROKE+4 → 테두리 STROKE//2 = 7px@1400)를 원본 px로 환산해 쓴다. `svg_img`는 resvg에 높이만 준다(너비·높이를 같이 주면 너비 기준이라 높이가 어긋났다). 6개 포즈 × 높이 820·1436에서 높이 일치, 너비 0~2px(반올림), 바깥선 위치 평균 0.5px 이내, 불투명 영역 IoU 0.98~0.99. 남은 차이: PNG 테두리는 흐림(blur 1px)으로 부드럽고 SVG는 또렷하다.
- 어두운 배경 비교: `svg_img('point',820)`은 PNG와 모양이 같고, `ink='#1F2A44', paper='#F3E9D2'`는 남색 정장·크림색 셔츠·크림색 테두리로 나옴. `svg_img('point', 6000)` 얼굴 확대도 선이 선명함.
- `tests/test_scenes.py` 39개 통과(바꾸기 전과 같은 개수).
